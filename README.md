# by-dp.de - Digitale Lösungen

Offizielle Website und App-Launcher für by-dp.de.

## Lokal starten

**Voraussetzungen:** Node.js

1. Abhängigkeiten installieren:
   ```bash
   npm install
   ```
2. Entwicklungsserver starten:
   ```bash
   npm run dev
   ```
3. Für Produktion bauen:
   ```bash
   npm run build
   ```
